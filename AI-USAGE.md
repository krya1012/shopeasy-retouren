# Dokumentation der KI-Nutzung (Übersicht)

**GitHub-Repository:** [https://github.com/krya1012/shopeasy-retouren](https://github.com/krya1012/shopeasy-retouren)

Laut Aufgabenstellung führt undokumentierte KI-Nutzung zum Nicht-Bestehen. Deshalb gibt es **je Sprint eine Datei** mit allen Einträgen (Datum, Werkzeug, Co-Autor:in, Zweck, Prüfstatus).

**Regeln**
- Jede Person dokumentiert ihre eigene KI-Nutzung in der Datei des Sprints, in dem sie stattfindet, und zwar sofort.
- **Co-Autorenschaft:** Alle Einträge mit Claude Code entstehen in Sitzungen von **Yaraslau Krautsou** (Co-Autor von Claude Code). Andere Personen sind je Eintrag genannt, z. B. Eduard Ede Moser für die „Prozess Analyse der Shop Easy GmbH“.
- „offen – siehe Prüfliste“ wird erst durch das Ergebnis der Prüfung ersetzt, wenn jemand die Inhalte wirklich gelesen und geprüft hat.
- Die 2-seitige persönliche Zusammenfassung (Sprint 6) wird ohne KI erstellt.
- **Modell:** Claude Code mit der Einstellung `opusplan` (Claude Opus 5.5 im Planungsmodus, sonst Claude Sonnet 5.5; so auch in den Commit-Trailern vermerkt).
- **Git:** Der Autor der Commits ist Yaraslau Krautsou; Claude steht als Co-Autor im Commit-Trailer (`Co-Authored-By`). Frühere Commits trugen den Namen `utpbw`; die Datei `.mailmap` ordnet ihn Yaraslau Krautsou zu.
