# Documentation of AI Use (Overview)

**GitHub repository:** [https://github.com/krya1012/shopeasy-retouren](https://github.com/krya1012/shopeasy-retouren)

According to the task, undocumented AI use leads to failing. Therefore there is **one file per sprint** with all entries (date, tool, co-author, purpose, review status).

**Rules**
- Everyone documents their own AI use in the file of the sprint in which it happens, immediately.
- **Co-authorship:** all entries with Claude Code are created in sessions of **Yaraslau Krautsou** (co-author of Claude Code). Other people are named per entry, e.g. Eduard Ede Moser for the "Prozess Analyse der Shop Easy GmbH".
- "open – see checklist" is replaced by the result of the review only when someone has really read and checked the contents.
- The 2-page personal summary (Sprint 6) is written without AI.
- **Model:** Claude Code with the setting `opusplan` (Claude Opus 5.5 in planning mode, otherwise Claude Sonnet 5.5; also noted in the commit trailers).
- **Git:** the author of the commits is Yaraslau Krautsou; Claude is named as co-author in the commit trailer (`Co-Authored-By`). Earlier commits carried the name `utpbw`; the file `.mailmap` maps it to Yaraslau Krautsou.
- **Language:** the Sprint 1 files are German (as handed in). From Sprint 2 on everything is English.
